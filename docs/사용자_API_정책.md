# 사용자 소유 Gemini API와 사용량 정책

## 현재 구현 상태

현재 공개용 코드는 Phase 1 모의 데이터 앱입니다. 실제 Gemini 요청은 없으며 API 토큰 사용량은 0입니다.
모의 분석 버튼은 정해진 후보만 표시합니다. API 사용량 최적화를 완료한 실제 AI 서비스로 오해하지 않도록 구분합니다.

## 실제 AI 연결 시 적용할 기준

- 개발자 공용 키를 저장소에 포함하지 않습니다.
- 앱을 직접 운영하는 사람은 본인의 Gemini 키를 서버 비밀 환경변수로 설정합니다.
- 여러 이용자가 각자 키를 등록하는 서비스는 로그인, 사용자별 암호화 저장, 삭제·교체 및 권한 검증을 먼저 구현해야 합니다.
- 키를 브라우저 코드, VITE_ 환경변수, localStorage, 로그 또는 Git에 저장하지 않습니다.
- API 호출은 서버 프록시에서 처리하고 사용자의 키에 연결된 API 프로젝트 한도를 적용합니다.
- 무료 한도·모델 이용 가능 여부는 연결 시점에 확인하며 결제를 자동 활성화하지 않습니다.

## 토큰·호출 절감 설계

아래 정책은 실제 Gemini 연결 단계에서 구현·테스트할 계획이며 현재 모의 화면에는 API 호출이 없습니다.

1. 사진을 선택·교체하거나 입력을 수정할 때 자동 호출하지 않습니다. 명시적으로 분석을 요청할 때만 한 번 호출합니다.
2. AI에 보낼 사본만 크기를 줄이고 불필요한 이미지 메타데이터를 제거합니다. 원본 보관 사진과 구분합니다.
3. 물품 이름과 최대 3개의 태그만 짧은 JSON으로 요청합니다. 전체 물품 목록·이전 대화·긴 설명을 보내지 않습니다.
4. 출력 토큰 상한과 모델별 사고 토큰 설정을 서버에서 고정합니다. 브라우저에서 임의로 올릴 수 없게 합니다.
5. 같은 사용자·같은 사진·같은 모델·같은 프롬프트 버전의 결과를 재사용합니다. 사용자 간 캐시는 공유하지 않습니다.
6. 진행 중인 중복 요청을 합치고 자동 재시도는 기본 비활성화합니다.
7. 사용자별 일일 호출 제한과 동시 요청 제한을 서버에서 검사합니다. 다중 서버에서도 적용되도록 원자적으로 기록합니다.
8. 제공자가 반환하는 실제 토큰 사용량을 집계합니다. 예상 비용을 확정 비용처럼 표시하지 않습니다.
9. 한도 초과·오류가 발생해도 수동 물품 등록·수정을 계속 허용합니다.
