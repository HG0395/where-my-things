# 어디뒀지?

한국어 물품·보관 위치 관리 웹앱입니다. React, TypeScript, Vite, Tailwind CSS와 Supabase를 사용합니다.

## 현재 가능한 기능

- 공간 → 방 → 가구 → 서랍 형태의 위치 관리와 물품 등록·검색·수정·이동·삭제
- 사진 파일 선택·촬영 입력, 미리보기, 모의 AI 후보와 수동 보정
- Supabase 연결 후 이메일 로그인과 **이용자 각자의 Gemini 키 등록·교체·삭제**
- 서버 암호화, 사용자별 접근 제한, 사진 압축, 결과 캐시와 서버 호출 한도를 적용한 실제 AI 분석 코드

공개 소스에는 개인 프로젝트 연결 정보를 포함하지 않습니다. 설정 없이 실행하면 데모로 작동하고 외부 AI 요청은 없습니다. 실제 로그인·키 저장·분석은 [설정 안내](docs/사용자_API_설정.md)를 완료해야 사용할 수 있습니다.

물품·위치·원본 사진은 아직 브라우저 메모리에만 있습니다. 새로고침, 탭 종료, 로그인 계정 전환 시 초기화됩니다. PC·Android 동기화, 구성원 초대, 비공개 사진 저장과 배포는 구현하지 않았습니다. 키 관리 테이블의 RLS를 물품 공유 권한 구현으로 해석하면 안 됩니다.

## VS Code 실행

Node.js 24 이상을 설치한 뒤 VS Code에서 이 폴더를 열고 `터미널 → 새 터미널`을 선택합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

터미널의 Local 주소를 브라우저에서 여세요. 종료는 Ctrl+C입니다. 다음 실행에는 `npm.cmd run dev`만 필요합니다. PowerShell 실행 정책 문제를 피하려고 `npm.cmd`로 안내합니다. Node 설치 후 명령을 못 찾으면 VS Code를 다시 여세요.

개발 서버는 PC 내부 접속만 허용합니다. Android 실기기 접속과 공개 서비스 운영은 별도 설정이 필요합니다.

## 사용 방법

`물품 등록`에서 이름·수량·위치를 입력합니다. 사진·태그·메모는 선택입니다. 이름·태그·메모로 검색하고 위치를 선택하면 해당 하위 위치도 함께 표시합니다. 카드를 눌러 수정·이동·삭제할 수 있습니다. 삭제는 별도 확인을 거칩니다.

`위치 관리`에서 위치를 추가하거나 이름·부모·종류를 변경합니다. 자신·자손으로 이동할 수 없고 같은 부모 아래 이름 중복을 막습니다. 물품이나 자식 위치가 남아 있으면 삭제할 수 없습니다.

사진은 JPEG·PNG·WebP, 최대 5MB·4천만 화소를 허용합니다. HEIC는 변환이 필요합니다. 촬영 버튼의 동작은 기기에 따라 다릅니다. 모의 분석은 사진과 무관한 예제 후보입니다. 실제 분석은 로그인·본인 키 등록 후 전송 동의와 분석 버튼을 눌렀을 때 실행됩니다. 후보를 적용하고 직접 고친 다음 저장하세요.

## 사용자 API와 보호 방식

이용자는 `로그인·AI 설정`에서 본인의 Gemini 키를 등록합니다. 키는 HTTPS로 서버에 전송해 AES-256-GCM으로 암호화하여 저장하며, 브라우저 저장소나 코드에는 저장하지 않습니다. 운영자는 서버 암호화 키를 보유하므로 복호화할 수 있습니다. 종단간 암호화는 아닙니다.

AI에는 최대 1024px·512KiB JPEG 사본만 전송합니다. 사용자별 24시간 캐시, 하루 20회 시도, 요청 간격 20초, 동시 처리 1건을 서버에서 적용합니다. 출력 상한은 256토큰이며 자동 재시도는 없습니다. 자세한 기준은 [API 정책](docs/사용자_API_정책.md)을 확인하세요.

## 파일 구조

```text
src/features/auth/                 이메일 로그인·사용자 키 설정
src/features/items/                물품 입력·사진·AI 후보 적용
src/features/locations/             위치 트리·관리
src/domain/                        데이터 규칙
src/repositories/memory/            메모리 저장소
src/lib/                           Supabase·AI 요청·사진 처리
supabase/functions/                인증·암호화·Gemini 서버 호출
supabase/migrations/                키·캐시·사용량 테이블과 RLS
 tests/                            데이터·암호화·PostgreSQL 테스트
```

## 검사

```powershell
npm.cmd test
npm.cmd run lint
npm.cmd run build
npm.cmd run check:server
npm.cmd run test:server
npm.cmd run preview
```

서버 검사 명령은 처음 실행할 때 Deno 도구와 의존성을 내려받습니다. 테스트는 가짜 응답과 로컬 PostgreSQL 엔진을 사용하며 실제 Gemini나 Supabase에 연결하지 않습니다. 검증 범위는 [검증결과](검증결과.md)에 있습니다.

## 공개 저장소

숫자 IP와 개인 Windows 경로를 소스·안내에서 제거했습니다. 실제 환경변수·비밀키·설치 폴더·빌드·캐시는 Git에서 제외합니다. Gemini 키, service_role 키와 암호화 키를 `VITE_` 변수나 GitHub에 올리지 마세요. 유료 서비스·결제·배포는 활성화하지 않았습니다.
